# prop-mgmt

Unit Types Onboarding: an analyst uploads a new property's files, reviews one mapping, and downloads the unit type mapping workbook, the filled ETL workbook and the floor plans renamed to Rose names.

Status: design phase.

- [docs/PRD.md](docs/PRD.md): product requirements (MVP)
- [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md): proposed stack (React + TanStack Router/Query/Table, Hono API, pure TypeScript core) and open questions
- [mocks/index.html](mocks/index.html): clickable HTML mock of every screen. Open it in a browser; no build step.
